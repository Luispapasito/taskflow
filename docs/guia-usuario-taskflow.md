# Guía sencilla para TaskFlow

TaskFlow es una aplicación web para organizar tus tareas del día a día. Su objetivo es ayudarte a crear, ver, editar y eliminar tareas de forma rápida y ordenada.

## ¿Qué puedes hacer con TaskFlow?

TaskFlow permite:

- Crear una tarea nueva.
- Ver todas las tareas en una lista.
- Editar una tarea si cambias de idea o necesitas corregir detalles.
- Eliminar una tarea que ya no necesitas.
- Marcar el estado de cada tarea como pendiente, en progreso o completada.

## Requisitos para usar TaskFlow

Para abrir la aplicación necesitas:

- Un ordenador.
- Un navegador web, como Chrome, Edge o Firefox.
- Node.js instalado.

## Cómo arrancar TaskFlow

1. Abre la carpeta del proyecto.
2. En una terminal, escribe:

```bash
npm start
```

3. Espera a que la aplicación se inicie.
4. Abre tu navegador y entra a esta dirección:

http://localhost:3000

## Cómo crear una tarea

1. Pulsa el botón “Nueva tarea”.
2. Escribe un título corto y claro para la tarea.
3. Añade una descripción opcional con más detalles.
4. Elige el estado de la tarea:
   - Pendiente
   - En progreso
   - Completada
5. Pulsa “Guardar tarea”.

La tarea aparecerá en la lista principal.

## Cómo ver tus tareas

En la pantalla principal verás todas tus tareas. También puedes filtrar la lista para ver solo:

- Todas
- Pendientes
- En progreso
- Completadas

## Cómo editar una tarea

1. Busca la tarea en la lista.
2. Pulsa el botón “Editar”.
3. Cambia el título, la descripción o el estado.
4. Pulsa “Guardar tarea”.

## Cómo eliminar una tarea

1. Busca la tarea en la lista.
2. Pulsa el botón “Eliminar”.
3. Confirma la eliminación si la aplicación lo solicita.

## Significado de los estados

- Pendiente: la tarea todavía no ha empezado.
- En progreso: la tarea ya está en ejecución.
- Completada: la tarea ya está terminada.

## Consejos útiles

- Usa títulos cortos y fáciles de entender.
- Añade descripciones para explicar mejor una tarea.
- Actualiza el estado cuando cambie el progreso.
- Elimina tareas que ya no sean necesarias.

## Resumen

TaskFlow es una herramienta sencilla para llevar una lista de tareas y controlar tu trabajo de forma organizada. Gracias a ella puedes recordar qué debes hacer, ver el progreso y completar tus tareas con mayor claridad.
